# MVP

## Objectif
Livrer une première version utile pour un étudiant en architecture de 1re ou 2e année.

## Cas d'usage prioritaires
1. Comprendre un cours
2. Préparer ou améliorer un projet
3. S'entraîner avec des exercices
4. Obtenir une correction guidée
5. Retrouver une information dans ses documents

## Fonctionnalités MVP
- chat spécialisé architecture
- upload de documents
- import Google Drive
- recherche documentaire par RAG
- réponses avec contexte et références
- mémoire de projet simple
- génération d'exercices
- synthèse de cours

## Non-objectifs MVP
- rendu final de projet automatisé
- multi-agents avancés
- moteur 3D
- conformité réglementaire exhaustive
- support multi-utilisateur complexe

## Critères de succès
- réponses moins génériques
- recherche dans les documents de l'étudiant
- coût infra faible
- coût IA maîtrisé
- expérience simple pour un étudiant débutant

## Format de réponse attendu
Quand pertinent :
- cours
- règle générale
- source réglementaire locale

## Dépendances
- workspace maître
- choix du stack technique
- Trello MCP connecté
- stratégie d'ingestion documentaire
