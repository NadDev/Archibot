# Archibot

Assistant IA pour étudiant en architecture.

## But du projet
Construire un produit centré sur :
- l'aide aux cours
- l'aide à la production de projets
- la génération d'exercices et de corrections guidées

## Principes de base
- RAG dès le départ
- réponses non génériques
- séparation claire entre : cours, règle générale, source réglementaire locale
- infra low-cost
- Trello piloté via MCP, pas à la main
